# PDF Trans Studio

PDF စာအုပ်/စာတမ်းတွေကို လက်နဲ့ ဘာသာပြန်ဖို့ browser app ပါ။ [Sagar](https://github.com/saturngod/Sagar) (EPUB ဘာသာပြန် app) ရဲ့ ပုံစံကို ယူထားပါတယ်။

## သုံးနည်း

1. `index.html` ကို Chrome / Edge နဲ့ ဖွင့်ပါ (double-click)။
2. PDF ကို ဆွဲထည့်ပါ — စာမျက်နှာအလိုက် အပိုဒ်တွေ ခွဲထုတ်ပေးပါမယ်။
3. ဘယ်ဘက်မှာ မူရင်း၊ ညာဘက်မှာ ဘာသာပြန် ရေးပါ။ အလိုအလျောက် သိမ်းပါတယ်။
4. စာမျက်နှာတစ်ခုချင်းကို **✓ စစ်ပြီး** ဒါမှမဟုတ် **မူရင်းထား** လို့ မှတ်ပါ။
5. **Export** — PDF (print)၊ Word (.doc)၊ .txt၊ ဒါမှမဟုတ် backup (.json)။

## Feature များ

- ဒေတာ အားလုံး browser ရဲ့ IndexedDB ထဲမှာပဲ သိမ်းပါတယ်။ Server ကို မပို့ပါ။
- **စာသား** mode: မူရင်းအပိုဒ်နဲ့ ဘာသာပြန်ကို တန်းညှိပြီး ပြတယ်။ **စာမျက်နှာ** mode: PDF စာမျက်နှာ ပုံနဲ့ ဘေးချင်းယှဉ်ပြတယ်။
- အပိုဒ်ပေါ် mouse တင်ရင် **ပေါင်း / ခွဲ / ဖျက်** လုပ်လို့ရတယ် (PDF က စာထုတ်တာ မှားနေရင် ပြင်ဖို့)။
- **✨ AI**: လက်ရှိစာမျက်နှာအတွက် prompt ကို copy ကူးပြီး Claude / ChatGPT ထဲ ထည့်ပါ၊ ပြန်ရတဲ့ `[1] ... [2] ...` အဖြေကို paste လုပ်ရင် အကွက်တွေထဲ ဖြည့်ပေးပါတယ်။
- Export အပြည့်အစုံလုပ်ဖို့ စာမျက်နှာတိုင်း စစ်ပြီးဖြစ်ရပါမယ်။ မပြီးသေးရင် Draft အဖြစ် (မပြန်ရသေးတဲ့နေရာ မူရင်းစာနဲ့) export လုပ်လို့ရပါတယ်။
- Shortcut: `Ctrl+Enter` = နောက်အပိုဒ်၊ `Alt+←/→` = စာမျက်နှာ ရှေ့/နောက်။

## သတိပြုရန်

- ပထမဆုံးဖွင့်တဲ့အခါ pdf.js နဲ့ font ကို internet ကနေ load လုပ်ရပါတယ်။
- Scan ဖတ်ထားတဲ့ (ပုံ) PDF တွေမှာ စာသား ထုတ်လို့ မရပါ — OCR အရင်လုပ်ဖို့ လိုပါတယ်။
- Export က PDF ရဲ့ မူရင်း layout ကို မထိန်းထားပါ။ ဘာသာပြန်ထားတဲ့ စာသားကို စာမျက်နှာအလိုက် စာရွက်အသစ်အဖြစ် ထုတ်ပေးတာပါ။
- Browser data ကို ဖျက်လိုက်ရင် ဘာသာပြန်တွေပါ ပျက်သွားပါမယ်။ **Backup (.json)** ကို မကြာခဏ ထုတ်ထားပါ။
